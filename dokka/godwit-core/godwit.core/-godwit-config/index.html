val adoptApplied: (MongoDatabase) -> Set<String>?

For adopting a database migrated by another tool, or by hand: returns the ids of the migrations already applied to the database it is given. The app writes it; godwit knows nothing of any other tool's records.

val outOfOrder: OutOfOrder

What happens to a pending once-only migration listed before an applied once-only migration, or before an applied id that the supersedes list of a later migration not yet applied names. Repeatable and every-start history documents and unknown ids never make a once-only migration out of order.
